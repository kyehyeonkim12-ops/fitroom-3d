# 핏룸 3D

몸 치수로 만든 3D 마네킹에 쇼핑몰 실측대로 옷을 입혀 보고, 부위별로 얼마나 끼거나 넉넉한지 확인하는 웹앱입니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 http://localhost:8123 을 엽니다. 빌드 과정은 없고, Three.js는 CDN에서 불러옵니다.

## 기능

- **1단계 · 내 몸 모델**: 키, 몸무게, 어깨너비, 둘레(목·가슴·허리·엉덩이·허벅지·종아리·위팔), 팔·다리·종아리 길이를 입력하면 그 비율대로 마네킹이 바뀝니다. 치수는 브라우저에 자동 저장됩니다.
- **2단계 · 옷 입히기**: 옷 사진 1장과 실측(단면)을 넣으면 부위별 여유를 판정하고("어깨 여유 2cm, 가슴 꽉 낌, 기장은 엉덩이선 아래 5cm"), 3D 옷을 입히고, 사진에서 대표색이나 무늬를 가져와 씌웁니다. 핏 지도는 끼는 곳을 빨강, 넉넉한 곳을 파랑으로 표시합니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/measurements.js` | 몸 치수 항목, 평균 체형 추정, 저장 |
| `src/bodyModel.js` | 치수 → 3D 인체 메시. 단면 정보(`profile`)도 반환 |
| `src/garment.js` | 옷 실측 ↔ 몸 단면 비교, 3D 옷 메시 생성 |
| `src/fit.js` | 판정 기준값, 핏 지도 색, 요약 문장 |
| `src/photo.js` | 사진 배경 제거, 대표색·무늬 추출 |
| `src/viewer.js` | Three.js 장면, 카메라, 치수선 |
| `src/garmentPanel.js` | 옷 입히기 탭 UI |
| `src/main.js` | 내 치수 탭 UI, 전체 연결 |

판정 기준(둘레 여유 cm)은 `src/fit.js`의 `THRESHOLDS`에서 조정할 수 있습니다.
